# Структура проекта — app-dev

```

│   ├── config/             # Конфигурация

│   ├── constants/          # Константы
│   │   └── intervals.js
│   ├── pages/              # Страницы
│   │   ├── AdminPage.jsx

│   │       ├── shared.js
│   │       ├── EQQueueTab.jsx
```
