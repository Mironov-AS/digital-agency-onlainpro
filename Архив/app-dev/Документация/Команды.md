# Команды запуска — app-dev

## Разработка

```bash
cd /home/user/app-dev

# Установка зависимостей
npm install

# Dev-сервер (localhost)
npm run dev

# Продакшен-сборка
npm run build

# Preview продакшен-сборки
npm run preview

# Линтинг
npm run lint

# Тесты
npm run test           # run once
npm run test:watch     # watch mode
```

## Тесты

- Vitest + @testing-library/jest-dom + @testing-library/react
- jsdom для эмуляции DOM
- Файл тестов: `src/App.test.jsx`
