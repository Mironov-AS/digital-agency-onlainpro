# Электронная очередь — продукт на полке

## Суть

Продукт «Электронная очередь» на продуктовой полке агентства объединяет ранее
отдельный микросервис `queue-service` (репозиторий `Mironov-AS/queue-service`)
в основное SPA цифрового агентства.

Авторизация остаётся **централизованной** в основном приложении
(cookie-based JWT с refresh через `/api/auth/*`); никаких отдельных логинов
для очереди не требуется.

## Структура

```
src/
├── App.jsx                              # роутинг, в т.ч. /queue/visitor
├── pages/
│   ├── ElectronicQueuePage.jsx          # точка входа с вкладками
│   └── queue/
│       ├── shared.js                    # константы, форматтеры
│       ├── EQQueueTab.jsx               # вкладка «Очередь»
│       ├── EQTicketsTab.jsx             # вкладка «Талоны»
│       ├── EQServicesTab.jsx            # вкладка «Услуги» + поля формы
│       ├── EQStatsTab.jsx               # вкладка «Статистика»
│       ├── EQLogsTab.jsx                # вкладка «Журнал»
│       ├── EQUsersTab.jsx               # вкладка «Пользователи»
│       ├── EQSettingsTab.jsx            # вкладка «Настройки»
│       ├── EQQRTab.jsx                  # вкладка «QR-коды»
│       └── EQVisitorPage.jsx            # публичный киоск посетителя
└── config/services.js                   # пункт меню «Продуктовая полка»
```

## Вкладки админки

| Вкладка          | Что делает                                                          |
|------------------|---------------------------------------------------------------------|
| Очередь          | Текущий вызов, список ожидания, кнопки «Следующий / Повтор / Вернуть / Завершить», сброс очереди |
| Талоны           | Все талоны за дату с фильтрами; ручная регистрация; редактирование, перевод на другую услугу |
| Услуги           | CRUD услуг + доп. поля (text/phone/number/date/email/textarea) с флагами «обязательное» и «проверка дублей» |
| Статистика       | Сводка по дням и услугам, выгрузка в CSV                              |
| Журнал           | История действий (вызов талона, изменение услуги и т.д.)             |
| Пользователи     | Операторы и рекламодатели, сброс пароля                               |
| QR-коды          | Генерация QR для посетителя и терминала                               |
| Настройки        | Запись открыта/закрыта, автооткрытие/автосброс, мин. длина поля, смена своего пароля |

## Публичный киоск посетителя

URL `/queue/visitor` открывает полноэкранную страницу регистрации талона
без авторизации (использует публичные endpoint'ы `/api/services`,
`/api/services/:id/fields`, `/api/tickets`, `/api/service-fields/check-duplicate`,
`/api/settings/registration`). Эту страницу можно открывать с QR-кода в зале.

(см. `vite.config.js`). На production-сервере проксирование/роутинг
должно быть настроено так, чтобы cookie `/api/auth/*` оставались валидными
для всех перечисленных путей.

## Подключение продукта

Продукт активируется автоматически, если в каталоге продуктов на полке есть
товар с `code` ∈ {`queue`, `electronic-queue`, `eq`}. На карточке такого
продукта появляется кнопка «Открыть админку», в подписках — метка «встр.».

Для ручного добавления создайте запись в `/api/product-shelf/products`:

```json
{
  "code": "queue",
  "name": "Электронная очередь",
  "description": "Цифровая очередь с записью и оповещением",
  "show_on_landing": true,
  "price_monthly": 5000,
  "price_yearly": 50000
}
```
