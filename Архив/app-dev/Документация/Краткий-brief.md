# Краткий Brief — app-dev

## Суть проекта

React SPA-приложение (демо/заготовка) с базовыми CRUD-страницами для управления клиентами, каталогом услуг, проектами и финансами.

## Технологический стек

- **Framework:** React 19
- **Build tool:** Vite 8
- **UI icons:** lucide-react
- **Testing:** Vitest + Testing Library
- **Linting:** ESLint

## Страницы

- LoginPage — авторизация
- DashboardPage — главная панель
- ClientsPage — список клиентов
- ClientDetailPage — детали клиента
- CatalogPage — каталог услуг
- ProjectsPage — проекты
- OrgCostsPage — организационные расходы
- ProductShelfPage — продукты/подписки
- AdminPage — администрирование
- ElectronicQueuePage — админка продукта «Электронная очередь» (см. `Электронная-очередь.md`)

## Компоненты

- AppShell — обёртка приложения
- ConfirmModal — модальное окно подтверждения
- ServiceCard — карточка услуги

## Текущий статус

Разработка/прототипирование. Простой CRUD-интерфейс.

Функционал электронной очереди интегрирован в основное приложение (ранее — отдельный микросервис `Mironov-AS/queue-service`); авторизация централизована.
