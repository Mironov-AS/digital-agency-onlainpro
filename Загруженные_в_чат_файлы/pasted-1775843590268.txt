BUG-008 — Прогресс производственной задачи принимает значения > 100%
Поле	Значение
ID	BUG-008
Название	Поле progress задачи производства не ограничено диапазоном 0–100
Модуль	backend/src/routes/production.js → PUT /api/production/tasks/:id
Шаги воспроизведения	PUT /api/production/tasks/1 с телом {"progress": 150}
Ожидаемый результат	HTTP 400 или значение автоматически зажато в [0, 100]
Фактический результат	HTTP 200, поле progress: 150 сохранено в БД
Приоритет	P2
Серьёзность	Средний
Доп. материалы	На UI Gantt-диаграмма рендерит полосу выполнения на основе этого значения — возможен выход за пределы блока
