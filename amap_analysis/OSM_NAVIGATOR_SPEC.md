# OSM Navigator Pro - Спецификация

## Концепция и Видение

**OSM Navigator Pro** — это полноценное Android-приложение для автомобильной навигации с открытыми картами OpenStreetMap, оптимизированное для России. Приложение обеспечивает офлайн-навигацию, голосовые подсказки и отображение российских дорожных знаков.

Целевая аудитория: водители в России, которым нужна бесплатная навигация без зависимости от китайских сервисов.

## Технический стек

### Мобильное приложение
- **Платформа**: Android (Kotlin)
- **Картографический движок**: osmdroid 6.x
- **Маршрутизация**: GraphHopper (OSM данные)
- **Голосовая навигация**: Android TTS (русский)
- **Офлайн-карты**:Mapsforge vector tiles + OSM tile download
- **UI**: Material Design 3

### Архитектура
```
app/
├── data/           # Репозитории, источники данных
├── domain/         # Use cases, бизнес-логика
├── presentation/   # UI (MVVM)
└── core/           # Общие компоненты
```

## Ключевые функции

### 1. Карта
- [ ] Отображение OSM-карты с тайлами

### 2. Навигация
- [ ] Построение маршрута A→B
- [ ] Несколько вариантов (быстрый/короткий/эко)
- [ ] Избегание платных дорог, паромов
- [ ] Пересчёт при сходе с маршрута
- [ ] Симуляция маршрута

### 3. Голосовые подсказки
- [ ] Русский TTS

- [ ] Анонс расстояния: 500м, 200м, 100м

### 4. POI и поиск
- [ ] Поиск по адресу (Nominatim)

### 5. Российские дорожные знаки (шилды)
- [ ] М1-М12: федеральные трассы (зелёные)
- [ ] А100-А200: региональные (синие)
- [ ] Р200+: территориальные (красные)

## Интеграция OSM

### Источники данных

1. **OSM Extracts для России**
   - https://download.geofabrik.de/russia.html
   - Формат: OSM PBF (Protobuf)
   - Размер: ~500MB для полной России

2. **OSRM Demo Server**
   - http://router.project-osrm.org
   - Бесплатный, с ограничениями

3. **GraphHopper Maps**
   - Docker-образ для self-hosted routing
   - Поддержка OSM PBF

### Офлайн-тайлы
- https://tile.openstreetmap.org
- zoom levels 1-17
- Кэширование в SQLite
