# Краткий Brief — Цифровое агентство ОнлайнПро.РФ

## Суть проекта

SaaS-платформа для управления digital-агентством: клиенты, услуги, подписки, финансы, проекты, CRM, электронная очередь, бронирование, ERP, интернет-магазин.

## Основные продукты

| Продукт | Назначение | Порт/URL |
|---------|------------|----------|
| **Landing** | Маркетинговый сайт агентства | 5173 |
| **App (CRM Light)** | Админ-панель для сотрудников | 5174 |
| **Client Portal** | Личный кабинет клиента | 5202 |
| **Queue Dashboard** | Электронная очередь | 3002 |

## Микросервисы (бэкенд)

- `auth-service` (4001) — авторизация, JWT, 2FA
- `catalog-service` (4002) — каталог услуг
- `clients-service` (4003) — клиенты, платежи
- `projects-service` (4004) — проекты
- `admin-service` (4005) — управление пользователями
- `product-shelf-service` (4006) — продукты и подписки
- `queue-service` (3001/3002) — электронная очередь
- `booking-service` (4008) — бронирование
- `crm-service` — CRM (customers, orders, activities, statistics)
- `erp-service` — ERP-система
- `store-service` — интернет-магазин
- `label-merger-service` — объединение этикеток Ozon

## Технологический стек

**Frontend:** React 19 + Vite
**Backend:** Express.js + PostgreSQL
**Gateway:** Nginx
**Infrastructure:** Docker + Docker Compose
**Аутентификация:** JWT + bcrypt + speakeasy (2FA)

## Роли пользователей

- `admin` — полный доступ
- `user` — сотрудник (по умолчанию)
- `client` — клиент (личный кабинет)

## Текущий статус

Активная разработка. Есть Docker-инфраструктура, dev-скрипты, продакшен docker-compose.
