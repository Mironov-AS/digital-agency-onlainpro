# Структура проекта — digital-agency

## Корневая структура

```
digital-agency/
├── landing/                 # Маркетинговый лендинг (React + Vite)
├── app/                     # CRM Light / админ-панель (React + Vite)
├── client-portal/           # Личный кабинет клиента
├── marketing/               # Маркетинговые страницы
├── gateway/                 # Nginx gateway (Dockerfile)
├── services/                # Микросервисы (Express)
├── shared/                  # Общий код
├── scripts/                 # Утилиты (backup, etc.)
├── docs/                    # Документация
├── .env.example             # Шаблон переменных окружения
├── docker-compose.yml       # Продакшен-инфраструктура
├── Dockerfile               # Multi-stage build
├── deploy-nginx.conf        # Nginx-конфиг
├── promto.yaml              # Promto-конфиг
└── ARCHITECTURE.md          # Описание архитектуры
```

## Структура микросервисов (services/)

```
services/
├── auth-service/            # Авторизация, JWT, 2FA
│   ├── src/
│   ├── data/                # SQLite (dev) или search_path=auth (prod)
│   └── Dockerfile
├── catalog-service/         # Каталог услуг
├── clients-service/          # Клиенты, платежи
├── projects-service/         # Проекты
├── admin-service/           # Управление пользователями
├── product-shelf-service/    # Продукты, подписки
├── queue-service/           # Электронная очередь (+ dashboard)
├── booking-service/         # Бронирование (+ dashboard)
├── crm-service/             # CRM: customers, orders, activities
├── erp-service/             # ERP (+ client)
├── store-service/            # Интернет-магазин (+ client)
├── label-merger-service/     # Объединение Ozon-этикеток
└── furniture-photo-sorter-service/  # Сортировка фото
```
