```
┌─────────────────────────────────────────────────────────┐
│                    Nginx Gateway (8080)                  │
│          / → landing  |  /app → React SPA               │
│          /client → Client Portal                         │
│          /api/* → microservices                          │
└─────────────────────────────────────────────────────────┘
                          │
    ┌─────────┬──────────┼──────────┬──────────┬─────────┐
    ▼         ▼          ▼          ▼          ▼         ▼
  auth      catalog    clients   projects   admin    product-shelf
 (4001)    (4002)     (4003)     (4004)     (4005)     (4006)
    │         │          │          │          │          │
    └─────────┴──────────┼──────────┴──────────┴──────────┘
                         ▼
              ┌─────────────────────┐

              └─────────────────────┘
```

## Backend (микросервисы Express)

### auth-service (4001)
- JWT access/refresh токены
- bcryptjs хеширование паролей
- speakeasy 2FA
- refresh_tokens в БД
- **search_path:** `auth`

### catalog-service (4002)
- Каталог услуг, категории, типы стоимости
- **search_path:** `catalog`

### clients-service (4003)
- Клиенты, подписки, платежи
- Организационные расходы
- **search_path:** `clients`

### projects-service (4004)
- Проекты
- **search_path:** `projects`

### admin-service (4005)
- Управление пользователями
- Мониторинг статусов сервисов
- **search_path:** `public`

### product-shelf-service (4006)
- Продукты (по коду)
- Подписки на продукты
- **search_path:** `shelf`

### queue-service (3001/3002)
- API: 3001
- Dashboard: 3002
- QR-генерация (qrcode)

### booking-service (4008)
- Система бронирования

### crm-service
- Customers, employees, work records
- Activities (calendar/tasks)
- Sales items, orders, order items
- Statistics/reports

### erp-service
- ERP-функциональность
- Client-приложение

### store-service
- Интернет-магазин
- Client-приложение

### label-merger-service
- Объединение этикеток Ozon
- **search_path:** `label_merger,shelf`

### furniture-photo-sorter-service
- Сортировка фото мебели

## База данных

**Движок:** PostgreSQL 16
**Расположение:** Виртуальная машина (5.129.252.107:5432)
**База данных:** digital_agency
**Пользователь:** agency

**Схемы:**
- `auth` — пользователи, refresh токены
- `catalog` — каталог услуг
- `clients` — клиенты, платежи
- `projects` — проекты
- `shelf` — продукты
- `crm` — CRM (customers, orders, employees)
- `erp` — ERP данные
- `queue` — очередь
- `booking` — бронирование
- `admin` — админ данные
- `label_merger` — объединение этикеток
- `furniture_sorter` — сортировка фото
- `store` — интернет-магазин

**Backup:** `scripts/backup-pg-vm.sh`

## Infrastructure

- **Gateway:** Nginx (docker)
- **Containers:** Docker Compose
- **Health checks:** wget /api/health на каждом сервисе
- **Restart:** unless-stopped

## Безопасность

- helmet — HTTP headers
- cors — настроенный CORS_ORIGIN
- express-rate-limit — rate limiting
- JWT secrets минимум 32 символа
- bcryptjs для паролей
