# Команды запуска и сборки — digital-agency

## Локальная разработка

```bash
# Установка зависимостей (монорепозиторий)
npm install

# Запуск всех frontend-приложений
npm run dev

# Или по отдельности:
npm run dev:landing          # landing (5173)
npm run dev:auth              # auth-service (4001)
npm run dev:catalog           # catalog-service (4002)
npm run dev:clients           # clients-service (4003)
npm run dev:projects          # projects-service (4004)
npm run dev:admin             # admin-service (4005)
npm run dev:product-shelf     # product-shelf-service (4006)
npm run dev:queue             # queue-service (3001)
npm run dev:queue-client      # queue dashboard (3002)
npm run dev:booking           # booking-service (4008)
npm run dev:booking-client    # booking dashboard
npm run dev:erp               # erp-service
npm run dev:erp-client        # erp dashboard
npm run dev:store             # store-service
npm run dev:store-client      # store dashboard
npm run dev:ozon-labels       # label-merger-service
```

## Docker (продакшен)

```bash
# 1. Настройка окружения
cp .env.example .env
# Заполнить: JWT_ACCESS_SECRET, JWT_REFRESH_SECRET, CORS_ORIGIN, DATABASE_URL, ADMIN_EMAIL, ADMIN_PASSWORD

# 2. Сборка
docker-compose build

# 3. Запуск
docker-compose up -d

# 4. Проверка статуса
docker-compose ps

# 5. Проверка health
curl http://localhost:8080/api/health

# Остановка
docker-compose down
```

## Скрипты

```bash
# Мониторинг сервисов
node service-monitor.js

# Бэкап всех БД
./scripts/backup.sh

# Бэкап с ротацией (cron)
./scripts/backup.sh --keep 14

# Запуск сервисов
./start-services.sh

# Запуск всего
./start.sh

# Тестовый набор
node test-suite.js
```

## Тесты

```bash
# Внутри app/
npm run test          # vitest run
npm run test:watch    # vitest (watch mode)
npm run lint          # eslint
```

## Сборка frontend

```bash
# В landing/, app/, client-portal/
npm run build         # Vite build → dist/
npm run preview       # Preview продакшен-сборки
```
