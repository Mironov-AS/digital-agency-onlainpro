## Логотип Гексагон

Логотип символизирует:
- **Стабильность** — шестиугольник одна из самых устойчивых форм
- **Технологичность** — ассоциация с кристаллами, сотами, молекулами
- **Связность** — шесть вершин как точки соединения элементов
- **Современность** — минималистичный дизайн с neon-эффектами

### Варианты логотипа

| Файл | Описание | Применение |
|------|----------|------------|
| `logo-modern-4-hexagon.svg` | Основной с анимацией | Hero-секции, презентации |

## Правила использования

### ✅ Можно
- Использовать фирменные цвета в любых комбинациях
- Комбинировать градиенты purple → cyan
- Применять glow-эффекты для акцентов
- Использовать тёмный фон как базовый
- Анимировать логотип и иконки

### ❌ Нельзя
- Использовать другие оттенки фирменных цветов
- Добавлять яркие цвета (красный, жёлтый, зелёный)
- Использовать светлый фон без крайней необходимости
- Искажать или деформировать логотип
- Удалять анимации без согласования
